# ケルト十字タロット

ジャンルを選ぶだけで、ケルト十字（10 枚）のタロット占いができる Web アプリ。1 つの HTML ファイルで完結し、スマホで遊ぶことを前提に作っている。LLM や外部 API は使っていない。

公開版: https://kaito-tsuruishi.github.io/tarot-celtic-cross/

## 遊び方

1. テーマ（総合・恋愛・仕事・人間関係）を選ぶ。恋愛を選んだときは、続けて「片思い・これから」「交際中・パートナーあり」のどちらかを選ぶ
2. 山札が切られ、10 枚がケルト十字の形に配られる
3. 光っているカードをタップするか、画面下のボタンで 1 枚ずつめくる。めくるとシートが開き、ポジション名・カード・正逆・解釈文を表示する
4. 10 枚めくると総合リーディングが表示される

めくったカードはもう一度タップすると読み返せる。ブラウザを再読み込みしても、同じタブ内なら途中の状態に戻る。

## 構成

```
data/          解釈データ（JSON）
  *.json         78 枚 × キーワード・基本の意味・4 ジャンル × 正逆の「現在」枠の文（624 文）
  love-status/   恋愛の文のうち、交際前か交際中かで読み方が変わるものの反対側の版
  frames/        ポジション別の文（障害・目標・内面・過去・未来・姿勢・環境・願望と恐れ・結末。5,616 文）
src/           アプリ本体
  index.html     画面と CSS
  art.js         カード絵柄の SVG 生成
  reading.js     総合リーディングの生成
  app.js         画面制御（配置・めくり・シート・状態の保存と復元）
scripts/
  validate.js        data/*.json の検証（文字数・禁止語・重複・欠け）
  validate-frames.js data/frames/*.json の検証（現在枠との重複・決まり文句の偏り）
  validate-love-status.js data/love-status/*.json の検証（状況にそぐわない語・元の文との重複）
  build.js           データと src/ を 1 つの HTML に結合して dist/index.html を生成
dist/index.html  ビルド成果物（これだけで動く）
tests/selftest.js ブラウザ内で動く回帰テスト（scripts/serve-test.js で配信したときだけ差し込まれる）
docs/
  handover.md        受領時の引き継ぎ資料
  writing-guide.md   解釈文の執筆ガイド
  frames-guide.md    ポジション別の文の執筆ガイド
  love-status-guide.md 恋愛の状況別の文の執筆ガイド
  research-notes.md  総合リーディングの読み筋の裏取り
.github/workflows/pages.yml  main への push で検証 → ビルド → GitHub Pages へデプロイ
```

## 開発

```bash
node scripts/validate.js data/*.json
node scripts/validate-frames.js data/frames/*.json
node scripts/validate-love-status.js data/love-status/*.json
node scripts/build.js
```

### 回帰テスト

```bash
node scripts/build.js
node scripts/serve-test.js        # http://localhost:8766/?selftest
```

`?selftest` を付けて開くと、ページに `tests/selftest.js` が差し込まれ、実際のブラウザの中でアプリを自動操作して検査する。iOS シミュレータの Safari で開けば、実機と同じ WebKit で確かめられる（`xcrun simctl openurl booted http://localhost:8766/?selftest`）。終わると画面下に合否が出て、結果は `tests/report-<画面サイズ>-<時刻>.json` に保存される。

検査する内容: 全ジャンルと恋愛の 2 状況で 10 枚をめくる流れ、各ポジション専用の解釈文が出ること、シートが画面内に収まり開いても拡大しないこと、背景の固定と解除、総合リーディングの表示と並びから開くシート、もう一度占う、再読み込みからの復元、どの画面でも横にはみ出さないこと。スワイプで閉じる操作など、指の動きが要るものは対象外なので手で確認する。

`dist/index.html` をブラウザで開けば動く。サーバもビルドツールも不要。データや `src/` を直したら `build.js` を実行するか、main に push して GitHub Actions に任せる。

## 仕様

### デッキと配置

- 78 枚フルデッキ、逆位置あり（各カード 50%）。シャッフルは Fisher–Yates、乱数は `crypto.getRandomValues`
- ケルト十字の 10 ポジション。1 枚目の上に 2 枚目を横向きに重ね、右の列は下から 7 → 10

| # | ポジション | 時間枠 |
|---|---|---|
| 1 | 現状 | 現在 |
| 2 | 障害・課題 | 障害 |
| 3 | 顕在意識・目標 | 目標 |
| 4 | 潜在意識・土台 | 内面 |
| 5 | 過去 | 過去 |
| 6 | 近い未来 | 未来 |
| 7 | 本人の姿勢 | 姿勢 |
| 8 | 周囲の環境 | 環境 |
| 9 | 願望と恐れ | 願望と恐れ |
| 10 | 最終結果 | 結末 |

### 解釈文

- 1 枚のカードに「キーワード（正逆）」「基本の意味（正逆）」「4 ジャンル × 正逆 × 10 ポジション」の文がある。合計 6,240 文
- 解釈文は置かれたポジションごとに専用（現状／障害／目標／潜在意識／過去／近い未来／本人の姿勢／周囲の環境／願望と恐れ／最終結果）。1 枚目「現状」の文が土台で、ほかの 9 つはそれを各ポジションの視点に移し替えて書いている
- 文はすべてオリジナル。60〜120 字・2 文（状態＋助言）・です・ます調。不安をあおる断定をしない。重いカード（死神・塔・ソードの 10 など）は「区切り」「急な変化」として書く
- 恋愛ジャンルは、交際前（片思い・これから）と交際中（パートナーあり）を最初に選んでもらう。恋愛の文の大半はどちらでも読める中立の文で、交際前か交際中のどちらかを前提にした文にだけ、反対側の版を用意して状況に応じて差し替える
- 書き方の詳細は `docs/writing-guide.md`、`docs/frames-guide.md`、`docs/love-status-guide.md`

### 総合リーディング

10 枚全体から当てはまる観点を選び、観点ごとに 3〜4 候補ある定型文をランダムに組み合わせる。根拠は `docs/research-notes.md`。

- 枚数の傾向: 大アルカナ（6 枚以上 / 4〜5 枚 / 1 枚以下）、同じスートが 4 枚以上、出ていないスート、逆位置（8 枚以上 / 6〜7 枚 / 1 枚以下）、コートカード（4 枚以上 / 3 枚 / 0 枚）、同じ数字が 3 枚以上
- ポジションの組み合わせ: 1 と 2、5 → 1 → 6、3 と 4、7 と 8、9 と 10、3 と 10（補助に 4）。カードの基調（明るい／中立／重い）を比べて分岐する
- 元素の相性（エレメンタル・ディグニティ）: 中央の 1 枚目と十字で接する 5 枚の元素（火・水・風・地。大アルカナは占星術の対応）を比べ、強め合う／打ち消し合う配置のときに 1 段落入る
- 最終結果が大アルカナなら「特に重く」、コートカードなら「その人物次第」の一文
- 締めは 10 枚目の「最終結果」枠の解釈文
- 再読み込みで復元したときに同じ文面になるよう、スプレッドごとに seed を持つ

### カードの絵柄

ライダー版（ウェイト＝スミス版）の絵柄は使わず、SVG で描いたオリジナル。

- 共通: 羊皮紙の地に、スートごとの差し色（ワンド＝朱、カップ＝青緑、ソード＝鋼、ペンタクル＝緑金、大アルカナ＝金）の枠と四隅の飾り
- 数札: スート記号をトランプ風に配置し、スートごとの薄い地模様を敷く
- コートカード: 中央に大きなスート記号、ペイジ → キングで冠と台座の装飾が増える
- 大アルカナ: 金の地模様 → 墨の主モチーフ → 金の副モチーフの 3 層。番号はローマ数字
- 裏面: 織り模様の地に、点の環と八芒星の紋章

### 画面と操作

- スマホ前提のレイアウト（375px 幅で崩れない）。カード幅は画面幅から計算
- 配る演出: 山札のシャッフル → 1 枚ずつ所定の位置へ。めくる演出: 画面内に収めてから持ち上がりながら反転 → 一拍おいてシートが開く
- シート（`<dialog>`）: 上部の帯を下に引くと閉じる。表示中は背景のスクロールを固定し、閉じると元の位置に戻す。Esc・背景タップ・ボタンでも閉じる
- 画面下に固定の操作バー（次のカード／総合リーディングへ）と、10 個の進捗ドット
- 占いの状態（ジャンル・10 枚・めくった枚数・seed）を `sessionStorage` に保存し、再読み込みで復元
- 引っ張り更新の抑止、キーボード操作、`prefers-reduced-motion`（演出をすべて省略）に対応
- 書体は Google Fonts の Noto Serif JP。通信が無い環境では端末の明朝体に戻る
