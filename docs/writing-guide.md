# 解釈データ 執筆ガイド

78 枚のカードごとに、キーワード・基本の意味・6 ジャンル × 正位置/逆位置の解釈文を JSON で書く。
このアプリで一番大事なのは解釈の質。文章はすべてオリジナルで書く（解説サイトの文章を書き写さない）。

## ファイルと形式

- 1 ファイル = 1 グループ（`data/major-a.json` など）。トップレベルは配列。
- 書き終えたら必ず `node scripts/validate.js data/<file>.json` を実行し、ERROR 0 にする。WARN もできるだけ解消する。
- id / nameJa / nameEn / arcana / suit / rank は検証スクリプト内の `EXPECTED` と完全一致させる（名前の表記: `ワンドのエース`, `ワンドの2`〜`ワンドの10`, `ワンドのペイジ`, `ワンドのナイト`, `ワンドのクイーン`, `ワンドのキング`。英語は `Ace of Wands`, `Two of Wands` … `Ten of Wands`, `Page of Wands` …）。

## 文章のルール

1. **長さ**: 1 つの解釈は 60〜120 字（検証は 50〜140 字を必須範囲とする）。改行は入れない。文末は「。」。
2. **構成**: 「いまの状態」＋「どうするとよいか」の 2 文構成。3 文までは可。
3. **文体**: です・ます調で統一。「〜な流れです」「〜しやすい時期です」「〜が鍵になります」「〜とよいでしょう」。
4. **時制を限定しない**: 10 のポジション（現状・過去・近い未来・最終結果など）のどこに置かれても読めるように、「今日」「今週」「来月」など具体的な時間は書かない。
5. **不安をあおらない**: 「必ず」「絶対」「〜してしまいます」のような断定で恐怖を与えない。死神・塔・ソードの 10・ソードの 3 などは「終わりと再出発」「急な変化」「区切り」「手放し」として書く。
6. **逆位置は単なる「悪い意味」ではない**: 正位置の力が「弱まっている」「行き過ぎている」「内側に向いている」「遅れている」のどれかで読む。重いカード（塔・死神・悪魔・ソードの 10 など）の逆位置は「峠を越えつつある」「抜け出しかけている」のような回復の兆しとして書いてよい。
7. **健康ジャンル**: 病名・症状を断定しない。死神・塔を病気や死として書かない。「生活リズム」「休養」「無理をしない」「心身のバランス」「体の声を聞く」といった方向で書く。以下の語は使わない: 病気 / 病名 / がん / 癌 / 腫瘍 / 手術 / 入院 / 死 / 診断 / 発症 / 感染 / うつ病 / 障害 / 余命 / 治療 / 薬（「必死」など熟語の一部でも検証で弾かれる）。
8. **ジャンルごとに書き分ける**: 同じカードの 6 ジャンルの文が、語尾だけ違う言い換えにならないようにする。それぞれのジャンルで具体的に何が起きやすいかを書く。
   - general（総合）: 人生全体・状況全体
   - love（恋愛）: 相手との関係、片思い・交際・パートナーシップ。相手は「相手」と呼ぶ
   - work（仕事）: 職場・キャリア・プロジェクト・学業
   - money（金運）: 収入・支出・貯蓄・投資・金銭感覚
   - relation（人間関係）: 友人・家族・職場の人・コミュニティとの関わり
   - health（健康）: 体調・生活習慣・心身のバランス
9. **同じスート内で文面を似せない**: 数字ごとのテーマの違いをはっきり出す。
   - 1=始まり・種 / 2=選択・均衡 / 3=成長・協力・最初の成果 / 4=安定・停滞 / 5=変化・葛藤・損失 / 6=調和・回復・移行 / 7=試練・見直し・忍耐 / 8=前進・力・動き / 9=到達目前・集大成 / 10=完結・次の周期へ
   - ペイジ=学び・知らせ・未熟な熱意 / ナイト=行動・移動・勢い（行き過ぎも） / クイーン=成熟した内面・受容・育てる力 / キング=統率・責任・完成した力
   - コートカードは「そのような資質を持つ人物が関わる」とも「本人にその資質が求められる」とも読めるように書く
10. **用語の統一**: 相手（恋愛の相手）、周囲（人間関係）、職場（仕事）。「カード」「このカードは」といった自己言及は本文には書かない（カード名は別途表示される）。
11. **キーワード**: 正位置・逆位置それぞれ 3〜5 個。1〜8 文字の名詞句。
12. **meaning（基本の意味）**: ジャンルに寄らないカードそのものの本質を書く。ここだけは「〜を表すカードです」「〜を示します」のように書いてよい。

## 解釈の軸

現代の主流（ライダー＝ウェイト＝スミス版系）の解釈を軸にする。ウェイト原典『The Pictorial Key to the Tarot』は補助として参照する（原典は現代と食い違う箇所が多いので、原典の意味を機械的に採用しない）。

スートの性質: ワンド=火・情熱・行動・意志・創造 / カップ=水・感情・愛情・人間関係 / ソード=風・思考・判断・決断・葛藤 / ペンタクル=地・お金・仕事・物質・身体・現実的な豊かさ。
