# 恋愛ジャンルの状況別の文 執筆ガイド

恋愛ジャンルでは、占う前に「いまの状況」を 2 択で選んでもらう。

| key | 表示 | 含む状況 |
|---|---|---|
| single | 片思い・これから | 気になる人がいる、出会いを待っている、相手はいるがまだ付き合っていない、復縁を望んでいる |
| couple | 交際中・パートナーあり | 付き合っている、結婚している、一緒に暮らしているパートナーがいる |

恋愛の文（78 枚 × 正逆 × 10 ポジション = 1,560 文）のほとんどは「相手との関係」と書かれていて、どちらの状況でも読める。これを **neutral（中立）** として両方で使う。
どちらかの状況を前提にしていて、反対の状況の人が読むと話が噛み合わない文だけ、反対側の版を用意する。

## 判定の基準

- **single 前提**: 告白する／されていない、片思い、出会い、まだ付き合っていない、距離を縮める、連絡先を交換する、好意に気づいてもらう、など。交際中の人が読むと「もう付き合っているのに」となる文
- **couple 前提**: 交際している、同居・結婚・婚約、二人の暮らし・将来設計、記念日、倦怠期、パートナーとしての役割分担、など。交際前の人が読むと「まだ付き合っていないのに」となる文
- **both**: 「片思いなら〜、交際中なら〜」のように 1 文の中で両方に触れている文。状況が分かれば片方だけで足りるので、single 版と couple 版の両方を書き直す
- **neutral**: 「相手との関係」「相手の気持ち」「二人の距離」など、どちらの状況でも違和感がない文。迷ったら、反対の状況の人が読んで引っかかるかどうかで決める。少しでも引っかかるなら neutral にしない

## 反対側の版の書き方

- 元の文と同じカード・同じ正逆・同じポジションの視点（現在、障害、目標、心の奥、過去、近い未来、本人の構え、周りからの影響、望みと恐れ、たどり着く先）を保ち、状況だけを反対側に移す
- 例: 恋人（正位置）・近い未来・single 前提「告白がうまくいき、二人の関係が始まる流れが入ってきます」→ couple 版「二人の関係が一段深まり、改めて互いを選び直すような出来事が入ってきます」
- 60〜120 字、2 文（状態＋助言）、です・ます調、不安をあおらない。相手は「相手」と呼ぶ
- 元の文と冒頭 18 文字を同じにしない。語尾だけ変えた文にしない
- single 版には「交際中」「同居」「結婚生活」「夫婦」「記念日」「倦怠期」を、couple 版には「片思い」「告白」「出会い」「まだ付き合って」を入れない（検証で弾かれる）

## ファイル形式

`data/love-status/<グループ>.json` に、**neutral 以外の文だけ**を並べる。

```json
[
  { "key": "major-06|up|future", "side": "single", "alt": "（couple 版の文）" },
  { "key": "cups-10|up|now", "side": "couple", "alt": "（single 版の文）" },
  { "key": "cups-02|up|now", "side": "both", "single": "（single 版）", "couple": "（couple 版）" }
]
```

- `key` は `カードid|up または rev|ポジションの枠`
- `side` は元の文が前提にしている状況。`alt` は反対側の版
- 書き終えたら `node scripts/validate-love-status.js data/love-status/<グループ>.json` を実行し、ERROR 0 にする
