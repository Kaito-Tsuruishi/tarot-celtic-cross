# 時間枠別の解釈文 執筆ガイド

ケルト十字の 10 ポジションを 4 つの「時間枠」にまとめ、カード × 正逆 × ジャンルごとに枠別の解釈文を持たせる。
既存の解釈文（`data/*.json` の `genres.<genre>.up / .rev`）は「現在」枠として使う。新しく書くのは残り 3 枠。

| 枠 | key | 含むポジション | 視点 |
|---|---|---|---|
| 現在 | now | 1 現状・2 障害・課題・7 本人の姿勢・8 周囲の環境 | いま働いている影響（既存文をそのまま使う） |
| 内面 | inner | 3 顕在意識・目標・4 潜在意識・土台・9 願望と恐れ | 本人が意識していること、心の奥で感じていること、望みや恐れ |
| 過去 | past | 5 過去 | 過ぎ去った、または過ぎ去りつつある影響。いまに残っているもの |
| 未来 | future | 6 近い未来・10 最終結果 | これから働き始める流れ、たどり着く先 |

## 書き方

1. **「現在」の文を読んでから書く**。カードの意味とジャンルの具体性は現在枠の文に出そろっているので、それを時間枠の視点に移し替える。意味を変えない。
2. **語尾の置き換えで済ませない**。「〜な流れです」→「〜な流れでした」のような変換は不可。枠ごとに「何を見ているか」を変える。
   - inner: 「〜と感じている」「〜を望んでいる」「〜を恐れている」「頭では〜と思っている」のように、本人の内側の動きとして書く。助言は「その気持ちにどう気づくか・どう扱うか」。
   - past: 「〜という時期を通ってきた」「〜の影響が薄れつつある」「〜の名残がいまも…」のように、終わった、または終わりつつある出来事として書く。助言は「何を持ち越し、何を手放すか」。
   - future: 「〜が入ってくる」「〜へ向かっていく」「〜という形に落ち着く」のように、これから起きる流れ・着地点として書く。助言は「それをどう迎えるか・備えるか」。
3. **長さ**: 60〜120 字。2 文構成（状態＋助言）。改行なし。文末は「。」。です・ます調。
4. **不安をあおらない**。「必ず」「絶対」「〜してしまいます」を使わない。重いカードは「区切り」「手放し」「急な変化」として書く。
5. **逆位置**は現在枠と同じ読み（弱まり／行き過ぎ／内向き／遅れ）を保つ。
6. **現在枠の文と似せない**。冒頭 18 文字が一致してはいけない。同じ文を時制だけ変えたものも不可。
7. 恋愛は相手を「相手」と呼ぶ。「カード」「このカードは」といった自己言及は書かない。
8. **決まり文句に頼らない**。同じ枠の中で書き出しと言い回しを 3 種類以上使い分ける。特に次の語は便利だが、1 ファイル内で 3 割を超えて使わない（検証で警告が出る）。
   - past: 「名残」「手放す」「持ち越す」「時期が遠ざかる」
   - future: 「流れがこれから来ます」「近づいています」「入ってきます」
   - inner: 「心の奥で」「心のどこかで」
   代わりに、その枠で起きる具体的な出来事・気持ち・場面を書く（例: past なら「あのとき言えなかった一言」、future なら「久しぶりの連絡」「評価が形になる場面」など）。
9. ジャンルごとの具体性は現在枠の文から引き継ぐ。仕事なら職場・案件・評価、人間関係なら友人・家族・集まり、総合なら暮らし全体の出来事を書く。

## 例（愚者・恋愛・正位置）

- now（既存）: 肩の力が抜けた、素のままの関わりが始まりやすい流れです。駆け引きや先の計算を手放し、一緒にいて楽しいという気持ちを大切にすると関係が動きます。
- inner: 条件や将来のことより、ただ一緒にいて楽しい関係を心のどこかで望んでいます。その素直な気持ちを、恥ずかしがらずに自分で認めてあげることが先です。
- past: 深く考えずに飛び込んだ、軽やかな始まりを通ってきました。あの無邪気さはもう当たり前ではなくなりつつあるので、良かった部分だけを意識して残すとよいでしょう。
- future: 構えのない、素のままで向き合える関わりがこれから生まれてきます。計算して動くより、楽しいと思える方へ素直に足を向けると、その流れに乗れます。

## ファイル形式

```json
[
  {
    "id": "wands-01",
    "frames": {
      "love": {
        "up":  { "inner": "…", "past": "…", "future": "…" },
        "rev": { "inner": "…", "past": "…", "future": "…" }
      }
    }
  }
]
```

書き終えたら `node scripts/validate-frames.js <ファイル>` を実行し、ERROR 0 にする。
