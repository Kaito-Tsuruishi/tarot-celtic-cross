# 総合リーディングの読み筋 調査ノート

`docs/handover.md` の「6. 総合リーディングの組み立て」と「3. ケルト十字の10ポジション」の読み筋が、一般的な読み方として裏付けられるかを調べた結果。

## 調査の前提

- 結論の区分: 「採用してよい」= 複数の情報源で同趣旨を確認 / 「条件付き」= 方向性は裏付けられるが、しきい値・ポジション番号などに調整が必要 / 「定説なし」= 情報源間で一致せず、または直接の記述を確認できず
- 確認した情報源はいずれも実践者の解説サイトで、体系的な標準規則は存在しない。しきい値は「アプリとしての設計値」として決める必要がある
- 日本語の情報源（tazn、coconala など）を検索・閲覧したが、枚数のしきい値や逆位置・スート偏りの読み方を具体的に述べたものは見つからなかった。日本語側は、数字の重複・偶奇・大小の偏りの読み方（tazn）が確認できた程度
- ポジション番号の付け方は流派で異なる。本アプリの番号はウェイト原典（3=上=顕在、4=下=土台、5=過去、6=近い未来）。Biddy Tarot や Joan Bunning（learntarot.com）は 3=過去、4=近い未来、5=上（顕在）、6=下（潜在）の並びで、ペアの番号が一致しない。以降は本アプリの番号に読み替えて整理した
- 参考: 10 枚を 78 枚のデッキから引いた場合の出現確率（本ノート筆者による計算。逆位置は各カード 50%）

| 事象 | 確率 |
|---|---|
| 大アルカナ 3 枚以上 / 4 枚以上 / 5 枚以上 / 6 枚以上 | 58% / 30% / 11% / 2.6% |
| 特定スートが 4 枚以上 / 5 枚以上 | 7.3% / 1.4%（4 スートのどれかなら約 25%） |
| いずれかのスートが 0 枚 | 43%（特定スートが 0 枚なら 12%） |
| コートカード 2 枚以上 / 3 枚以上 / 4 枚以上 | 66% / 33% / 11.5% |
| 逆位置 6 枚以上 / 7 枚以上 / 8 枚以上 | 38% / 17% / 5.5% |
| 1〜10 の数札で同じ数字が 2 枚以上 / 3 枚以上 | 60% / 5.8% |

## 1. 大アルカナが多いときの読み方

**結論: 条件付き**（「多いと運命的・重い」という方向性は採用してよい。「4 枚以上」という枚数の定説はない）

**情報源と要点**
- https://tarotelements.com/celtic-cross-tarot-spread-indicators-of-success/ : ケルト十字で大アルカナが「過半数」なら、本人の力の及ばない大きな影響が働いていると読む。小アルカナが過半数なら本人が主導権を握っており、選択肢も多い。数値のしきい値は示されていない
- https://biddytarot.com/?p=708 : 大アルカナは長期的・普遍的な力、小アルカナは今の生活への現れ方という役割の違いを説明している。枚数のしきい値の記述はない
- https://learntarot.com/exer12.htm : ケルト十字で大アルカナがどの位置に入っているかを観察する練習があり、大アルカナを人生の重要なテーマを示すものとして扱っている。枚数の目安は示されていない
- 日本語の検索では枚数の目安を扱った記事は見つからなかった。大アルカナ=人生の大きな流れ、小アルカナ=日常の出来事という役割分担の説明のみ確認

**アプリへの反映案**
- 判定は 3 段階にする: 大アルカナ 0〜1 枚=「日常の具体的な出来事が中心。本人の行動で変えやすい」/ 2〜3 枚=言及なし（出現が普通の範囲）/ 4〜5 枚=「人生の節目になるテーマが働いている」/ 6 枚以上=「過半数。本人の意思を超えた大きな流れが強い」
- 4 枚という値は定説ではなく、出現確率 30% で「やや多い」と言える設計値として採用する。「過半数=6 枚以上」は tarotelements の趣旨に合う（確率 2.6% の特別な場面）
- 「運命で決まっている」とは断定せず、「大きな流れの中でどう動くかが問われる」という言い方にする（10 枚目は「現状の延長」の結果であり、変えられるという読み方が複数の情報源で共通。項目 6 参照）

## 2. 特定のスートが多い／まったく出ていないときの読み方

**結論: 条件付き**（スート=元素の対応と「多いならそのテーマが中心、無いならその領域が欠けている」は採用してよい。枚数のしきい値は定説なし）

**情報源と要点**
- https://tarotelements.com/celtic-cross-tarot-spread-indicators-of-success/ : 過半数のスートはその性質が前面に出る（ワンド=エネルギー・行動、カップ=感情、ソード=コミュニケーション・決断、ペンタクル=安定、または停滞）。出ていない元素はその状況に欠けているもの（ソード不在=明確な思考が少ない、カップ不在=感情が少ない、ワンド不在=エネルギー不足、ペンタクル不在=土台がまだ固まっていない）。ワンド・ソードは動きが速く、カップ・ペンタクルは動きが遅いというタイミングの読みもある
- https://biddytarot.com/?p=10207 : スートが出ていないことは、対応する元素の生活領域（例: ペンタクルなし=お金や安定への未表明の不安）を示すと読む。ただし不在の読み方はこの記事では占星術的な見方として扱われており、タロット固有の決まりではない。大アルカナが欠けたスートを補うこともある
- https://biddytarot.com/?p=1466 : あるスートが多数派のとき、質問そのものは変えず「そのスートのテーマがこの状況にどう影響しているか」を問う（例: 人間関係の相談でペンタクルが多いと、お金や仕事の圧力を示唆）。「過半数」「半分」といった緩い表現で、数値の基準はない
- 日本語の検索ではスート偏りの読み方を直接述べた記事は見つからなかった（スートの基本象徴のみ）

**アプリへの反映案**
- スートの集計対象は小アルカナのみ。大アルカナは含めない
- 偏り判定: 同じスートが 4 枚以上=「そのテーマが中心」（確率 7.3%、4 スートのどれかで約 25% なので毎回は出ない）。5 枚以上=「強く偏っている」
- 欠け判定: 小アルカナが 6 枚以上出ているのに特定スートが 0 枚のときだけ「欠け」を言及する（10 枚中に 0 枚は 43% で起きるため、小アルカナが少ないときの欠けは意味が薄い。この条件は筆者の設計案で情報源には無い）。複数スートが欠けるときは最も不足が目立つ 1 つか、「欠けたスートが 2 つ以上」として軽く触れる程度にとどめる
- 欠けの文は断定を避ける（「〜が見えにくい／まだ形になっていない」）。ペンタクル不在は「お金や仕事の話題は今回の中心ではない」とも読めるため、ジャンル（金運・仕事）と矛盾しない文言にする
- ワンド・ソード=動きが速い、カップ・ペンタクル=遅い、というタイミングの読みは出典が tarotelements 1 件のみのため、採用するなら補助の一文に留める

## 3. 逆位置が多いときの読み方（停滞・内向き・遅れ）

**結論: 採用してよい**（個々の逆位置の意味として「停滞・内向き・遅れ・行き過ぎ」は複数の情報源で一致。「逆位置が多い」ときの読みは方向性のみ裏付けあり、枚数のしきい値は定説なし）

**情報源と要点**
- https://angelorum.co/learn-tarot/7-ways-to-interpret-tarot-reversals : 逆位置の読み方として、遅れ・ブロック、内向き（内面で起きている）、不足、行き過ぎ、今すぐ向き合うべきというサイン、過去の見直し、まだ使われていない可能性、の 7 つを挙げる。多数の逆位置の読み方は扱っていない（逆位置はデッキの 1〜2 割程度が適切、半分を逆にすると読みが濁る、という運用の注意あり）
- https://learntarot.com/less17.htm : 正位置が多いとエネルギーが自由に流れ状況が成熟している、逆位置が多いとエネルギーが低く状況が不明瞭で、方向性の欠如・行き詰まり・落胆を示しうる。ただし未発達のエネルギーが別の方向に動く余地があり、変化の兆しとも読む、と説明している
- https://tarotelements.com/celtic-cross-tarot-spread-indicators-of-success/ : 逆位置が多いとブロックがあり、問題が相談者の想定より難しい可能性を示す。数値のしきい値は示されていない
- 日本語では逆位置の意味（弱まり・内向き・遅れ・行き過ぎ）は一般的だが、「多い」場合を扱った記事は見つからなかった

**アプリへの反映案**
- 逆位置の数が 5 枚（半分）なら期待値どおりなので言及しない。6〜7 枚=「流れがせき止められている、または内側で動いているテーマが多い。急がず整理する時期」/ 8 枚以上=「エネルギーが滞りやすく、状況がまだはっきりしない」（確率 5.5%）
- 逆位置 0〜2 枚（確率 5.5%）=「流れが比較的自由で、状況がはっきりしている」と読む（learntarot の趣旨）
- どの文も「悪い」と決めつけず、末尾に「変化の余地」を一言添える（learntarot が指摘）
- 本アプリは逆位置 50% 固定のため、「多い」の基準は一般的な運用（1〜2 割）ではなく 6 枚以上に置き直す必要がある。これは設計値であり、情報源の裏付けはない

## 4. コートカードが多いときの読み方（他人の関わり）

**結論: 採用してよい**（枚数の定説はないが、「複数なら人間関係・他者の関与が大きい」は複数の情報源で一致）

**情報源と要点**
- https://tarotelements.com/celtic-cross-tarot-spread-indicators-of-success/ : コートカードが多いと関係者が多く、支えになる場合も「船頭が多い」場合もある。コートカードがゼロなら他人は関与していない。しきい値は「a lot」とだけ書かれている
- https://theembroideredforest.com/blogs/tarot-spreads/family : ランクを役割に当てる読み方（ペイジ=年下、ナイト=同世代や行動する人、クイーン=養う立場、キング=守る・権威の立場）。複数のコートカードは登場人物として読み、2〜3 枚あれば関係性が主題だとする
- https://theembroideredforest.com/blogs/tarot-spreads/third-party : コートカードは実在の人物を表すことがあり、性別は一致しなくてよく、1 枚が集団（職場、近隣、家族の一派）を表すこともある。複数枚のときのしきい値は記述なし
- 日本語: tazn の記事にコートカードの総論的記述はあるが、複数枚の読みの具体的な基準は確認できなかった。コートカードを人物と読む考え方自体は一般的

**アプリへの反映案**
- コートカード 0 枚=「他人よりも本人自身の問題が中心」/ 1 枚=言及なし（通常の出現）/ 2 枚=言及なし or 「周囲の人の存在が意識される」/ 3 枚以上=「人間関係・他者の関与が大きい」（確率 33%）/ 4 枚以上=「関係者が多く、立場の調整がテーマ」（確率 11.5%）。2 枚で言及するかは任意（確率 66% で普通に起きるため、弱い文面にする）
- 「他人の関与」には、コートカードが人物ではなく本人の性格・態度を表している読み方もある。文面は「周囲の人、あるいは本人が担っている役割」と幅を持たせる
- コートカードがどのポジション（特に 7 本人 / 8 周囲 / 10 結果）にあるかで読みを変える。8 に出たら周囲の人物、7 に出たら本人の態度、10 に出たら項目 7 の扱い

## 5. 同じ数字が複数出たときの読み方と、数字 1〜10 のテーマ

**結論: 条件付き**（「同じ数字の重複はそのテーマの強調」「低い数字=始まり、高い数字=完結に向かう」は採用してよい。個々の数字のテーマは流派で差があり、重複枚数ごとの意味は定説なし）

**情報源と要点**
- https://biddytarot.com/blog/tarot-and-numerology/ : 数字ごとのテーマ（1=始まり・可能性、2=選択・バランス、3=成長・創造、4=安定・土台、5=葛藤・変化、6=調和・調整、7=内省、8=行動・力、9=完成間近、10=完了と再生）。同じ数字が多い場合の読みも列挙（1 が多い=始まったばかり、4 が多い=土台ができつつある、5 が多い=変化・揺れ、7 が多い=内省の時期、9 が多い=ほぼ完結、10 が多い=終わりが次の始まりに転じる、など）
- https://angelorum.co/topics/divination/a-guide-to-working-with-tarot-numerology : 数字の意味は固定せず、観察から自分のキーワードを育てるものとしつつ、暫定的に 1=発生、2=緊張・選択、4=構造、7=動き・試し、10=頂点・過剰、としている。同じ数字の重複は全体を貫くパターン。低い数字は形成途中、高い数字は蓄積や完成に近い状況を示し、4→5→6 のような連番は過程の進行を示す。10 は 1 に還元できるため、エースと響き合う
- https://tarotelements.com/celtic-cross-tarot-spread-indicators-of-success/ : 同じ数字が 2 枚以上、または明らかな数字のパターンがあると意味が加わる。高い数字が多ければ物事が終わりに近い。ゴールデン・ドーンの「重複数字が正確な出来事を示す」という読みには賛同していない
- https://tazn.substack.com/p/tazn2022717（日本語）: 同じ数字の重複はその数字のエネルギーの強調。奇数=能動・偶数=受動の偏り、小さい数=始まり・大きい数=成熟と終わりに近い、という偏りの読みも紹介。重複枚数のしきい値は示されていない

**アプリへの反映案**
- 数字 1〜10 のテーマ（アプリ用の統一キーワード）: 1=始まり・種 / 2=選択・均衡 / 3=成長・広がり / 4=安定・土台 / 5=変化・葛藤 / 6=調整・調和 / 7=内省・試される / 8=動き・力 / 9=完成間近 / 10=完結・次への移行。出典の最大公約数に沿っており、ほぼ全情報源と矛盾しない。なお tarotteachings.com（https://www.tarotteachings.com/number-meaning-of-tarot-cards.html）は 1〜9 を数秘術の人格論に近いテーマ（1=独立・意志、7=洞察、8=機会・循環）で示しており、上の表とは一部ずれる。ミニマルなタロット流の表を採用する
- 重複の判定: 1〜10 の数札だけで集計する。同じ数字が 2 枚=確率 60% で普通に起きる（言及しなくてよい、または軽く触れる）/ 3 枚以上=確率 5.8% で「その数字のテーマが全体を貫いている」と強く言及する。tarotelements の「2 枚以上」は出現が多すぎるため、アプリでは 3 枚以上を推奨（筆者の設計判断）
- 大小の偏り: 数札の平均が低い（1〜4 が中心）=「始まり・形成途中」/ 高い（8〜10 が中心）=「完結・終盤」。数札が 4 枚未満のときは判定しない
- 大アルカナの番号は読み替えず、数字集計から除外する（読み替えは出典に流派差がある: 14 を 5 にするか 4 にするかなど）
- 「重複数字で出来事の時期を特定する」ような読みは採用しない

## 6. ケルト十字のポジション同士の組み合わせ読み

**結論: 条件付き**（組み合わせ読みの考え方自体は一般的だが、ペアの内容は流派と番号で変わる。「9 と 10 の一致」「4 と 10 のつながり」は定説ではない）

### 6-1. 番号の対応（重要）

| 本アプリ（ウェイト番号） | Biddy / Bunning 番号での位置 |
|---|---|
| 3 顕在意識・目標（上） | 5（上、顕在） |
| 4 潜在意識・土台（下） | 6（下、潜在） |
| 5 過去（左） | 3（過去） |
| 6 近い未来（右） | 4（近い未来） |

したがって、情報源の「4 と 10」は本アプリの「6 と 10」、情報源の「5 と 10」は本アプリの「3 と 10」にあたる。handover の「4 と 10」をそのまま情報源の「4 と 10」で裏付けてはいけない。

### 6-2. ペアごとの裏付け

| ペア（本アプリ番号） | 裏付け | 情報源 |
|---|---|---|
| 1 と 2 | 採用してよい | 中心の十字として、2 枚が衝突する・支え合う、または 1 が中心課題で 2 が取るべき行動（Bunning）。tarotelements・Biddy も同趣旨 |
| 3 と 4 | 条件付き | 顕在と潜在の比較（Bunning は 3 と 5＝内なる真実と表向きの態度、Biddy は 5 と 6＝目標と無意識の動機）。一致しなければ無意識の影響を読み解く、という読み。本アプリの 3 と 4 に読み替えれば成立 |
| 5→1→6 | 採用してよい | 過去→現在→近い未来の流れとして一般的（Biddy・tarotelements・Waite の 5=過ぎ去る/6=働き始める）。本アプリでは 5 と 6 を左右固定とする方針と整合 |
| 7 と 8 | 採用してよい | 自分と、他者・集団・環境の対比（Bunning） |
| 9 と 10 | 条件付き | 願望・恐れ（期待）が結果の形に影響するという読み（Greer: https://marykgreer.com/2018/11/02/position-9-in-the-celtic-cross-spread/、tarotelements）。tarotelements は 9 のカードがそのまま結果になることもあると述べるが、「一致しているか確認する」を定式化した情報源は見つからなかった。Bunning は 9 を「どの位置とも組める補助カード」とし、10 との固定ペアにはしていない |
| 4 と 10 | 定説なし | 本アプリ番号の 4（土台）と 10（結果）を直接結びつけた記述は確認できない。Greer は 9（恐れ）と、十字の下のカード（本アプリの 4）の関連を見ることがあると述べる。Waite 自身は 10 を「他の全カードの影響の帰結」と定義しており（下記 §7 の原典）、4 も含めた全体の帰結として読むことはできるが、4 と 10 の専用ペアは筆者の推論 |
| 3 と 10（追加候補） | 採用してよい | 目標（期待）と結果の比較。Bunning と tarotelements が「一致なら信念が現実の流れと合っている、不一致なら信念か方針の見直し」と述べる（情報源での番号は 5 と 10） |
| 4 と 9（追加候補） | 条件付き | 無意識の動機と願望・恐れの関連（Biddy の 6 と 9、Greer の下のカードと恐れ）。情報源は 2 件 |
| 6 と 10（追加候補） | 条件付き | 近い未来が結果を形づくる（Biddy の「4 と 10」）。情報源は 1 件 |

**アプリへの反映案**
- 9 と 10: 「一致」ではなく「関係づけ」の文面にする。たとえば 9 と 10 のカードが同じスートまたは同じ大アルカナ属性なら「期待・不安がそのまま形になりやすい」、そうでなければ「期待や不安と結果は別物。結果は思い込みで決まらない」。一致を必須条件にしない
- 4 と 10: ペア扱いにするなら「補助」位置づけ（根っこの性質が結末にも表れている、という一文）とし、原典の根拠を主張しない。または 3 と 10（目標と結果）に差し替える
- ペア文は全てテンプレートの一文にとどめ、断定を避ける。出典側も「ペアは提案であり、全てのカードがペアになるわけではない」と明記している（tarotelements の looking-deeper 記事: https://tarotelements.com/celtic-cross-tarot-spread-looking-deeper/）
- 10 は「現状の延長にある結果」であり固定された運命ではない、という説明を結びに添える（Greer、tarotelements が同趣旨。Roxy API https://roxyapi.com/blogs/celtic-cross-tarot-spread-guide も検索結果の要約でのみ確認）

## 7. 10 枚目にコートカードが出たときの原典（Waite）の扱い

**結論: 採用してよい**（趣旨は「結末はそのカードの人物にかかっている」で合っている。ただし原典の後続の運用指示はアプリには反映しない）

**根拠となった原典**
- A. E. Waite, *The Pictorial Key to the Tarot*（1911）Part III §7「An Ancient Celtic Method of Divination」
  - 確認に使った閲覧先: https://neonvagabond.xyz/mirrors/sacred-texts/tarot/pkt/pkt0307.htm（sacred-texts.com のミラー）。元ページ https://sacred-texts.com/tarot/pkt/pkt0307.htm は自動取得時に 403 / ボット対策画面となり、本文は取得できなかった（回避はしていない）。可能なら元ページとの照合を推奨
- 要点（要約）: 10 枚目がコートカードの場合、占いの対象事項は最終的にそのカードが表す人物の手に落ち、結末は主にその人物に左右される、と述べる。原文の該当部分は "falls ultimately into the hands of a person represented by that card" の箇所
- 続けて、そのコートカードをシグニフィケーター（相談者を表すカード）として新たに占い直すと役立つとも述べる。さらに、最終カードが曖昧で結論を引き出せない場合は、10 枚目をシグニフィケーターとしてやり直すのがよいとも述べる
- 10 枚目の定義は「最終結果。他のカードの影響によってもたらされる到達点」、9 枚目は「本人の希望または恐れ」。3 は「目標・理想、手の届く最善だがまだ実現していないもの」、4 は「土台。すでに現実になり本人のものになったもの」、5 は「過ぎ去った、または過ぎ去りつつある影響」、6 は「働き始め、近い将来に作用する影響」。handover の 10 ポジション定義と一致する

**アプリへの反映案**
- handover の「事の行方はその人物次第」で趣旨は正しい。ただし原典は「最終的にその人物の手に渡る」というやや強い言い方なので、アプリ文面は「この件の結末は、このカードが表す人物（またはその人物の役割を担う誰か）の動きに大きく左右されます」程度にする
- 「その人物」が誰かの特定はしない。7（本人）・8（周囲）に出ているコートカードと同じスート・同じ階級なら、その人物を示唆する一文を足してもよいが、これは筆者の拡張案で原典の記述ではない
- 原典の「そのコートカードをシグニフィケーターにして占い直す」はアプリではシグニフィケーターを使わないため反映しない
- 他のポジションのコートカード（項目 4）と、10 枚目のコートカードの文を重複させない。10 枚目がコートカードのときは、項目 4 のコートカード集計の一文より 10 枚目の一文を優先する

## アプリの総合リーディングに採用する観点の最終リスト

1. 大アルカナの枚数: 0〜1 枚=日常の出来事が中心 / 2〜3 枚=言及なし / 4〜5 枚=人生の節目になるテーマ / 6 枚以上=本人の意思を超えた大きな流れ（4 は設計値。過半数=6 は出典の趣旨に合う）
2. 小アルカナ中心（大アルカナ 0〜1 枚）: 本人の選択と行動で動かせる余地が大きい
3. スートの偏り（小アルカナのみで集計）: 同スート 4 枚以上=そのテーマが中心、5 枚以上=強く偏る。ワンド=行動 / カップ=感情・関係 / ソード=思考・決断 / ペンタクル=お金・仕事・身体
4. 欠けたスート: 小アルカナ 6 枚以上で特定スートが 0 枚のときのみ言及。「その領域がまだ見えていない／形になっていない」と断定を避ける
5. 逆位置の数: 6〜7 枚=流れが滞る・内側で動く / 8 枚以上=エネルギーが滞りやすく状況が不明瞭 / 0〜2 枚=流れが自由で明確。いずれも変化の余地を添える。5 枚は言及なし
6. コートカードの数: 0 枚=他人より本人の問題 / 3 枚以上=人間関係・他者の関与が大きい / 4 枚以上=関係者が多く立場の調整がテーマ。位置（7・8・10）で人物の役割を読み分ける
7. 同じ数字: 数札で同数字 3 枚以上=そのテーマが全体を貫く（2 枚は軽く触れる程度か言及なし）。数字テーマは 1=始まり / 2=選択 / 3=成長 / 4=安定 / 5=変化・葛藤 / 6=調整 / 7=内省 / 8=動き・力 / 9=完成間近 / 10=完結・次への移行
8. 数字の大小の偏り: 低い数字が中心=始まり・形成途中 / 高い数字が中心=終盤・完結に近い
9. ポジション組み合わせ（本アプリ番号）: 1 と 2（核心の衝突または支え合い）/ 5→1→6（過去から未来への流れ）/ 7 と 8（本人と周囲の対比）/ 3 と 4（顕在意識と潜在意識のずれ）/ 3 と 10（目標と結果の一致・不一致）
10. 補助的な組み合わせ（弱い文面）: 9 と 10（期待や不安が結果にどう影響するか。一致は必須にしない）/ 4 と 9（無意識の動機と願望・恐れ）。4 と 10 は定説がないため、使うなら補助の一文にとどめる
11. 10 枚目の扱い: 大アルカナなら重く読む / コートカードなら「結末はその人物の動きに大きく左右される」/ いずれも「現状の延長にある結果であり、固定された運命ではない」と結ぶ
12. 全体の語り口: 枚数・偏りの読みは確定的に言い切らず、「傾向」として書く。複数の観点が同時に成立する場合は、強さ（出現確率が低いもの）を優先して 3〜4 個に絞る
