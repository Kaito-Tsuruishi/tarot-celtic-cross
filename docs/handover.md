# ケルト十字タロット占い 引き継ぎ資料（受領時点）

## 1. プロジェクト概要

ジャンルを選ぶだけで、ケルト十字（10枚）を使ったタロット占いができるWebアプリ。カードはランダムに引く。
このアプリで一番大事なのは解釈の質。実装より先に、解釈データを丁寧に作ること。

## 2. 確定した仕様

- 流れ：ジャンル選択 → シャッフル → 10枚配置 → 1枚ずつめくる → 総合リーディング
- 質問の入力欄は作らない
- ジャンルは6つ：総合、恋愛、仕事、金運、人間関係、健康
- デッキは78枚フル（大アルカナ22枚、小アルカナ56枚）
- 逆位置あり（各カード50%）
- カード画像はオリジナルデザイン。ライダー版（ウェイト=スミス版）の絵柄は再現しない。数字、スートの記号、抽象的なモチーフで表現する
- 1つのHTMLファイルで完結させる。スマホでも遊べるレイアウトにする
- 健康ジャンルには「医療の代わりではない」旨を一言添える
- アプリに LLM は組み込まない

## 3. ケルト十字の10ポジション

```
         [3]
   [5]  [1/2]  [6]        [10]
         [4]              [9]
                          [8]
                          [7]
```

1枚目の上に2枚目を横向きに重ねる。右側の4枚は下から7→8→9→10の順に並べる。

| # | 表示名 | 意味 |
|---|---|---|
| 1 | 現状 | 相談者や物事全体を包んでいる空気、いま働いている影響 |
| 2 | 障害・課題 | 立ちはだかっているものの性質。良いカードが出た場合は、障害は深刻ではない、または本来は良いものがこの件では裏目に出ている、と読む |
| 3 | 顕在意識・目標 | 本人が意識している目標や理想。この状況で手が届く最善の形だが、まだ実現していないもの |
| 4 | 潜在意識・土台 | 物事の根っこ。すでに現実になって本人に根付いているもの、心の奥にあるもの |
| 5 | 過去 | 過ぎ去った、または過ぎ去りつつある影響 |
| 6 | 近い未来 | これから働き始める影響 |
| 7 | 本人の姿勢 | この状況での本人の立場や態度 |
| 8 | 周囲の環境 | 周りの人、立場、環境がこの件に与えている影響 |
| 9 | 願望と恐れ | 望んでいること、または恐れていること。同じカードがどちらにも読める |
| 10 | 最終結果 | ほかの9枚の影響がたどり着く結末。大アルカナが出たら特に重く読む。コートカードが出たら「事の行方はその人物次第」と読む |

流派の扱い: 3枚目=顕在意識（原典では目標・最善の可能性）、4枚目=潜在意識（原典では土台）の両方を説明に含める。5=過去（左）、6=近い未来（右）で固定。シグニフィケーターは使わない。

## 4. 調査結果（要点）

- ウェイト原典§3の大アルカナの意味は現代解釈と食い違いが多い（星の正位置に「喪失」など）。方針: 現代主流（ライダー版系）を軸にし、原典は補助
- ジャンル別解釈を持たせる設計は英語圏の解説サイトでも一般的
- 逆位置は「弱まり・行き過ぎ・内向き・遅れ」と幅を持たせる
- スート: ワンド=火・情熱・行動 / カップ=水・感情・関係 / ソード=風・思考・葛藤 / ペンタクル=地・お金・仕事・身体

## 5. 解釈データ構造

`docs/writing-guide.md` を参照。

## 6. 総合リーディングの組み立て（案）

枚数の傾向（大アルカナ4枚以上 / 小アルカナ中心 / 特定スート偏り / 欠けたスート / 逆位置半分以上 / コートカード多数 / 同じ数字の複数出現）、数字のテーマ（1=始まり … 10=完結）、ポジションの組み合わせ（1と2 / 3と4 / 5→1→6 / 7と8 / 9と10 / 4と10）からテンプレート文を組み合わせ、最後に10枚目のジャンル別解釈で締める。

## 7. 完成の条件

- [ ] 78枚すべてに、キーワード、基本の意味、6ジャンル × 正位置と逆位置の解釈がそろっている
- [ ] 10ポジションの説明が画面に表示される
- [ ] 総合リーディングが、6章の観点を反映して毎回変わる
- [ ] ライダー版の絵柄を使っていない
- [ ] 健康ジャンルに注意書きがある
- [ ] スマホ幅（375px程度）で崩れない
- [ ] キーボードだけで操作できる。動きを減らす設定に対応している
